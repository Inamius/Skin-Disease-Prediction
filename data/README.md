# 📂 HAM10000 Dataset

This folder should contain the HAM10000 dataset files.

## Download Instructions

1. Visit: https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
2. Download and extract into this folder so the structure looks like:

```
data/
├── HAM10000_metadata.csv
├── HAM10000_images_part_1/
│   ├── ISIC_0024306.jpg
│   ├── ISIC_0024307.jpg
│   └── ...
└── HAM10000_images_part_2/
    ├── ISIC_0024308.jpg
    └── ...
```
