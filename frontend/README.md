# 🔬 DermScan Pro

AI-powered dermatoscopic lesion classifier using Deep Learning (InceptionV3) trained on the HAM10000 dataset. Built as a full-stack application with a React dashboard and FastAPI backend.

## 🚀 Quick Start (macOS M2)

### 1. Setup Python Environment

```bash
python3 -m venv myenv
source myenv/bin/activate
pip install -r backend/requirements.txt
```

### 2. Download HAM10000 Dataset

Download from [Kaggle](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000) and extract into `data/`.

### 3. Train the Model (~20 min)

```bash
cd notebooks
jupyter notebook classifier.ipynb
# Run all cells — trains 4 models, saves the champion
```

### 4. Start the Backend

```bash
cd backend
uvicorn main:app --reload --port 8000
# API docs: http://localhost:8000/docs
```

### 5. Start the Frontend

```bash
cd frontend
npm install
npm run dev
# Dashboard: http://localhost:5173
```

## 🏆 Model Tournament

4 architectures compete in a single-epoch battle on HAM10000:

| Rank | Model | Type | Accuracy |
|------|-------|------|----------|

| 🥉 | Custom CNN + BN | From Scratch | 42.30% |

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v1/health` | Server & model status |
| `POST` | `/api/v1/predict` | Classify a skin lesion image |
| `GET` | `/api/v1/model-info` | Model metadata & tournament results |
| `GET` | `/docs` | Swagger UI |
